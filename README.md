# Logic Legends — Student Assessment Framework

**Assess Students Across Coding, Aptitude, Communication & Domain Knowledge**

Logic Legends is an EduTech project focused on assessing students across four important dimensions: Coding, Aptitude, Communication, and Domain Knowledge. The goal is to identify student strengths, discover skill gaps, provide useful feedback, and track learning progress.

## Objectives

- Identify students' strengths and weaknesses.
- Evaluate technical and professional skills.
- Find skill gaps and recommend targeted learning.
- Use consistent scoring criteria for fair assessment.
- Track student improvement over time.
- Provide actionable feedback for continuous development.

## Assessment Categories

### 1. Coding — 30%

Evaluates programming and problem-solving abilities.

- Programming tasks with time limits.
- Code correctness and edge-case testing.
- Code readability and modularity.
- Debugging and problem-solving skills.
- Explanation of programming logic and design choices.

### 2. Aptitude — 25%

Measures logical, numerical, and analytical reasoning.

- Numerical reasoning.
- Logical sequences and patterns.
- Data interpretation.
- Analytical problem-solving.
- Accuracy and time management.

### 3. Communication — 20%

Evaluates the ability to express ideas clearly and work with others.

- Explaining a project or concept.
- Structured responses to scenarios.
- Active listening.
- Clarity and organization.
- Teamwork and collaboration.

### 4. Domain Knowledge — 25%

Measures understanding of subject-specific concepts and their applications.

- Core concept assessments.
- Applied case studies.
- Troubleshooting scenarios.
- Conceptual accuracy.
- Practical application and decision-making.

*The assessment weightings are illustrative and can be adjusted according to course requirements and learning objectives.*

## Scoring System

Each assessment category is scored on a scale of 0 to 5.

**Weighted Contribution = (Category Score / 5) × Category Weight**

**Overall Score = Sum of all weighted contributions**

The overall score helps summarize student performance across the four assessment categories. Scores should be interpreted alongside supporting evidence, feedback, and human review.

## Assessment Workflow

1. **Prepare:** Define learning outcomes, assessment criteria, and accessibility requirements.
2. **Assess:** Conduct standardized assessments with clear instructions and time limits.
3. **Review:** Check the evidence and ensure scoring consistency.
4. **Feedback:** Share strengths and two or three improvement priorities.
5. **Reassess:** Conduct comparable assessments to measure progress.

## Fairness and Accessibility

- Provide clear instructions and transparent scoring criteria.
- Use consistent assessment standards.
- Support accessibility needs and reasonable accommodations.
- Evaluate communication content separately from accent or presentation style.
- Use scores as guidance rather than as the sole basis for important decisions.

## Getting Started

To run the project locally, first ensure that Node.js and npm are installed.

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project directory:

   ```bash
   cd logic-legends
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

**Note:** These instructions assume the repository contains a working Vite project with the required scripts configured. If Supabase is used, configure the required environment variables and authentication settings before using database-dependent features. Never commit secret keys or private credentials to GitHub.
